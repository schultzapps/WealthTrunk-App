## Create a backup

**Settings → Import/Export Data → Create A Backup**, then save or share the file.

| Included | Not included |
| --- | --- |
| Accounts, balances, holdings | Attachment files (names are kept) |
| Profiles, photos, logos | App settings |
| Goals and records | |
| Custom types | |

## Restore a backup

:::danger
Restoring replaces all existing data. Create a backup first.
:::

**Settings → Import/Export Data → Restore From Backup**, or tap a backup file to open it in WealthTrunk.

## Copy data to a partner

Send them a backup to restore. Later changes won't sync between you.
